Add engine hooks. `RendererOptions.onPointer` reports `down`, `up`, `click`, `enter`, `leave` and `move` (at most once per animation frame) as a `ScenePointerEvent` with the nearest node under the pointer, selectable or not (grounds included), its `parentId` ancestors, the world point (the ground plane y = 0 on a miss), the pointer type, button, modifier keys and whether it came from the canvas or a label; a click handler can call `preventSelection()` to skip the default selection and framing, and selection is unchanged otherwise. `SceneRenderer.onFrame(listener, { step?, maxSteps? })` runs a listener once per rendered frame after node motion, or on a fixed simulation step (1/240–1/10 s) before node motion that stops while paused or hidden, keeps running with motion off, and runs at most `maxSteps` (default 4) steps per frame with the excess reported in `SceneFrame.dropped`; listener errors go to `onError`. `RendererOptions.plugins` takes mount-time `RendererPlugin`s (`{ name, setup(context) }`) that are set up after the first scene sync with access to the Three.js scene, the WebGL renderer, the current camera and read-only node objects, and cleaned up in reverse order before the renderer is disposed; duplicate names throw and a failing setup disposes the renderer and throws an error naming the plugin. The React and Vue `SceneCanvas` take `plugins` (mount-time), React an `onPointer` prop read through a ref (no remount) and Vue a validated `pointer` event, and both adapters add `useSceneFrame(listener, options)`.
