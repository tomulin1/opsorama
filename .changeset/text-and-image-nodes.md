Add text and image nodes. `TextNode` (`kind: 'text'`) draws 1–500 characters (`MAX_TEXT_LENGTH`; `\n` breaks lines) with `size` as the capital-letter height in metres (`TEXT_SIZE_RANGE` 0.05–20, `DEFAULT_TEXT_SIZE` 0.4), `color` (default: the palette `text` role, else the theme text color), `align` (`TEXT_ALIGNS`: `left`, `center`, `right`) and `billboard`. `ImageNode` (`kind: 'image'`) shows `src` on a rectangle of `size` [width, height] metres (each up to `MAX_IMAGE_SIZE`, 100) and takes `billboard`; `src` must be a relative, `http:`, `https:`, `blob:` or `data:image/` URL of at most `MAX_IMAGE_SRC_LENGTH` characters (`IMAGE_SRC_PATTERN`), so `javascript:` and other schemes, control characters and surrounding spaces are rejected. Like lines, text and images take no route or controller. `validateScene` and the scene JSON Schema cover both kinds with the new rules `text`, `text-size`, `image-src` and `image-size`, and `allowed-value` for `align`.

The renderer draws text into canvas textures with the labels' system font stack (no font files) on a plane, or on a camera-facing sprite with `billboard`; images load in the background with `crossOrigin = 'anonymous'` behind a neutral placeholder. Equal text (text, color, alignment) and equal image `src` share one texture per renderer, released with the last node that uses it, so `getDiagnostics().textures` returns to its earlier count; a node removed or changed before its image arrives never receives it, and an unneeded load is cancelled. A failed image keeps its placeholder and is reported to `onError` with `name` `IMAGE_LOAD_ERROR` and a message naming the node and the URL. Text and images are transparent and never instanced, merged, shadowed or covered by the glow style; picking accepts sprite hits, so pointer events and selection work on billboards. `disposeObject` now also disposes sprite materials (never the geometry all sprites share). The node preview has its own texture caches and redraws when an image arrives. New exports: `IMAGE_LOAD_ERROR`, `TEXT_COLORS`, `IMAGE_PLACEHOLDER_COLORS`, `TEXT_FONT`, `TEXT_CAP_PIXELS`, `MAX_TEXT_TEXTURE_SIZE` and `TEXT_LINE_SPACING`.

React and Vue add `SceneText` and `SceneImage` (named so they do not shadow the DOM `Text` and `Image`); Vue node components gain the `text`, `src`, `billboard` and `align` props, and `size` also accepts a number. Both `SceneCanvas` components report `IMAGE_LOAD_ERROR` errors to their error callback without covering the scene with the "Scene unavailable" panel.
